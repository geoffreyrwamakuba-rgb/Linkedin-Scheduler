The size of your CSV on disk doesn't tell you how much RAM pandas needs to load it.

A 100,000-row orders file is 5.3 MB as a CSV. Loaded with a plain read_csv, it took 7.7 MB in memory. Three changes brought it down to 1.3 MB.

Before you reach for chunking or a bigger machine, start here.

→ Measure first. Load a sample with nrows=100_000, then run df.memory_usage(deep=True).sum() to see its size in bytes. If the full file has 10 million rows, multiply by 100.

→ Load only the columns you use. usecols= drops the rest at read time, so they never reach memory.

→ Make repeated values categorical. A region column with four possible values gets stored as small integer codes plus one copy of each label. In this file it went from 1.25 MB to 0.1 MB.

→ Shrink the numbers. A column whose values stay within plus or minus 2.1 billion fits in int32, half the size of the default int64.

Do all of this before you split the file into chunks. Chunking has traps of its own.
